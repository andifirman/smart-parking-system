# Smart Parking ANPR

Smart Parking System using YOLO, OCR, Python,
FastAPI, React, and Arduino.

## Architecture

- apps/web: Frontend dashboard
- apps/api: Backend REST API
- apps/vision: Computer Vision inference
- ml: Model training and experimentation
- firmware: Arduino barrier controller
- data: Dataset and captures
- infrastructure: Deployment scripts
